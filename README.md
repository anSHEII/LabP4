Permite registrar trabajos científicos, como artículos, libros y páginas web, y relacionarlos con sus autores e investigadores. 
Además, ofrece funcionalidades para listar publicaciones por fecha y contenido temático, así como para eliminar registros existentes. 

El objetivo principal es modelar un entorno de investigación donde se pueda administrar bibliografía y consultar información relevante de manera organizada.
